# @freedomtalk/scripts

Development and deployment scripts for the FreedomTalk project.

## Purpose

This package contains utility scripts for:

- Database migrations and seeding
- Development environment setup
- Build and deployment automation
- Code generation
- Testing utilities

## Status

🚧 **Minimal implementation** - This package will be expanded as needed during development.

## Usage

Scripts will be added here as the project develops. Common scripts might include:

```bash
# Database migrations
npm run migrate

# Seed development data
npm run seed

# Generate types from database schema
npm run generate:types

# Deploy to production
npm run deploy
```

## Development

Scripts are written in TypeScript and can be executed using `tsx` or compiled to JavaScript.
