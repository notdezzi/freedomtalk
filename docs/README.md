# Docs

Project documentation is organized by purpose:

- `architecture/` - system design, implementation planning, and technical direction
- `setup/` - local environment and infrastructure guides
- `product/` - product positioning, feature inventory, and case-study material
- `roadmap/` - milestone and roadmap documents
- `plans/` - dated design proposals
- `process/` - workflow and tooling notes
- `archive/` - historical notes and superseded markdown plans
- `agent-guides/` - non-root agent-specific guidance that does not need to stay in the project root

For a fast start, see [`QUICKSTART.md`](./QUICKSTART.md).
